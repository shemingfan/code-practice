## 编译与运行

需要支持 C++11 及以上（部分文件用到了 `vector`、`auto`、范围 `for`）。

```bash
g++ -std=c++17 -O2 -static "1.cpp" -o 1.exe
./1.exe
```

用 Dev-C++ 的话直接打开 `.cpp` 文件按 F11 编译运行即可。仓库里**不包含**编译产物（`.exe`、`output/` 等已在 `.gitignore` 中排除）。

## 关于编码

源文件统一保存为 **UTF-8（无 BOM）**，换行符为 LF，这样在 GitHub 网页和 Linux 环境下中文注释都不会乱码。
